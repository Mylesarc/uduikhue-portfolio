# Local fonts

Inter and Space Grotesk are self-hosted from the official Google Fonts repository. Font files and their SIL Open Font License texts are retained in this directory. CSS uses font-display: swap and system fallback stacks. No runtime request to Google Fonts is needed.

Sources:
- https://github.com/google/fonts/tree/main/ofl/inter
- https://github.com/google/fonts/tree/main/ofl/spacegrotesk

The local original variable TTF files are used; no font conversion dependency was added.

JetBrains Mono is now self-hosted for technical labels and profile metadata. Source: https://github.com/google/fonts/tree/main/ofl/jetbrainsmono. Its original variable TTF and OFL licence are included.
