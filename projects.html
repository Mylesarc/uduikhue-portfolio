Working project / 01

Personal study planner

A working task manager for organising coursework: add tasks, mark them complete, delete them, and keep your list saved in this browser.

JavaScript / DOM / localStorage

Open study planner →
How it works

Built with plain JavaScript, an array of task objects, DOM updates, and localStorage. Tasks stay on this browser and device. Includes keyboard controls and graceful handling of unavailable storage.
